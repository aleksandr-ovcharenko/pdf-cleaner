# PDF Cleaner

PDF Cleaner - приложение для интерактивного выбора зон в PDF-документах, которые могут быть обработаны или удалены.

## Функции

- Открытие PDF-документов
- Интерактивное выделение зон на PDF-страницах
- Определение типа зоны (статическая или динамическая)
- Сохранение конфигурации выбранных зон

## Требования

- Python 3.6+
- PyMuPDF (fitz)
- Pillow
- tkinter (обычно поставляется с Python)

## Установка

```
pip install -r requirements.txt
```

## Использование

```
python pdf_cleaner.py
```

1. Нажмите на "Открыть PDF" для выбора PDF-файла
2. Выделите нужные зоны на документе, используя мышь
3. Определите тип каждой зоны (статическая или динамическая)
4. Нажмите на "Сохранить зоны" для сохранения конфигурации
